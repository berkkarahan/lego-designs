# New design template

Copy this folder into designs/<new-slug>/ after the concept is chosen. Replace the example requirements, diagram and step; they demonstrate the format and are not an actual buildable model.

Record:
- Concept, desired play behavior, audience and important user constraints.
- Chosen mechanisms, structural connections and controls.
- Stock assumptions and unresolved dimensions/compatibility.
- Conversation decisions, current progress and next steps.
- Links to parts.json, inventory-check.json, instructions.md, guide.json, diagrams/, build-guide.pdf and VERIFICATION.md when those files exist.

Use schema_version 1 and stock IDs from inventory/parts.json. Read docs/formats.md. Check stock, generate the guide, inspect all rendered pages, and record what was actually verified. Do not leave template examples in a final design.
